# Little Learners Studio

Você é um especialista em criação de web apps educacionais modernos utilizando o Lovable.



Sua missão é construir um **web app completo, funcional, responsivo e mobile-first**, transformando o produto descrito abaixo em uma experiência digital de aprendizagem organizada, envolvente e fácil de utilizar.



---



# PRODUTO



**MEU PRODUTO É SOBRE: educação infantil para crianças aprender ler e escrever e desenhar**



### REGRA PRINCIPAL



A linha acima é a única parte variável deste prompt.



Todo o restante da estrutura, experiência, navegação, funcionalidades e padrão visual deve permanecer.



O conteúdo das atividades, módulos e materiais deve ser adaptado automaticamente ao produto informado.

# 1. OBJETIVO DO APLICATIVO



Criar uma plataforma de aprendizagem que permita ao usuário:



* aprender através de atividades interativas;

* acompanhar o progresso;

* realizar exercícios;

* praticar escrita;

* desenhar;

* acessar materiais de apoio;

* imprimir atividades;

* guardar atividades como PDF através da impressão do navegador;

* retornar exatamente de onde parou.



O aplicativo deve parecer um **produto educacional digital completo**, e não apenas uma página web.



---



# 2. PÚBLICO



O produto é voltado para crianças, mas o aplicativo será utilizado principalmente pelo responsável através do celular.



Portanto:



* linguagem simples;

* interface amigável;

* atividades visuais;

* botões grandes;

* pouca leitura desnecessária;

* navegação extremamente simples;

* elementos que funcionem bem com toque.



O responsável deve conseguir entender rapidamente o que a criança deve fazer.



---



# 3. EXPERIÊNCIA MOBILE-FIRST



A prioridade absoluta é o celular.



O aplicativo deve:



* ser 100% responsivo;

* funcionar em smartphones Android;

* funcionar em tablets;

* funcionar em computadores;

* possuir botões grandes;

* possuir áreas de toque confortáveis;

* evitar elementos pequenos;

* evitar excesso de texto;

* carregar rapidamente;

* funcionar bem em conexões mais lentas.



Criar primeiro a versão mobile e depois adaptar para telas maiores.



---



# 4. TECNOLOGIA



Utilizar uma arquitetura moderna e simples.



Preferir:



* React;

* TypeScript;

* Tailwind CSS;

* componentes reutilizáveis;

* Lucide Icons;

* localStorage;

* HTML Canvas para desenho e traçado;

* CSS `@media print` para impressão.



Não adicionar bibliotecas desnecessárias.



Organizar o código de forma limpa e modular.
